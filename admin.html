BASE DE VENDEDORES

A consulta, inclusão e edição dos vendedores agora utiliza diretamente a aba Vendedores da planilha de TESTE. A situação do grupo é calculada automaticamente pelos telefones validados. As importações não alteram os telefones oficiais sem confirmação.

Conexão protegida pelo Google Apps Script
A API usa a planilha de TESTE e valida a identidade Google via Firebase Authentication no servidor. Nenhum token permanente é armazenado neste navegador.
Os vendedores serão carregados automaticamente após o acesso.

A API trabalha exclusivamente com a aba Vendedores (A:M). Telefone alterado volta para PENDENTE até ser validado explicitamente.
